# NIM Proxy 功能清单

| 属性 | 值 |
|------|-----|
| 版本 | v1.0 |
| 状态 | 稳定 |
| 最后更新 | 2026-11-23 |

## 第一部分：文档概述

按用户类型分章列出可操作的菜单与功能点，作为功能开发与权限配置依据。

### 1.1 背景与目标

明确管理员与客户端调用方各自的功能边界：管理员通过管理台治理密钥与观测用量；客户端调用方仅通过 API 使用中转。

### 1.2 文档定位

| 定位 | 说明 |
|------|------|
| 本文档做什么 | 按用户类型分章列菜单与功能点描述 |
| 本文档不做什么 | 不涉及技术实现、数据库设计、接口定义与系统架构 |

### 1.3 范围

| 范围 | 说明 |
|------|------|
| 业务域 | NIM API 中转服务 |
| 用户类型 | 管理员（Owner）、客户端调用方（ApiClient） |

## 第二部分：功能清单

### 本清单概览

管理员拥有管理台全部菜单（密钥管理、用量观测、运行配置）；客户端调用方无 UI 菜单，其功能为中转 API 调用（以功能点描述，非菜单）。

## 2.1 管理员（Owner）

**用户类型概述**：服务所有者，单管理员，经令牌登录管理台，治理密钥、观测用量、查看配置。

#### 2.1.1 支撑业务域

**应用域概述**：密钥治理与用量观测。

##### 2.1.1.1 S-01 密钥管理

**功能说明**：上游/客户端密钥维护与启停。

###### S-01-01 上游密钥维护

**功能说明**：上游密钥增删查与健康。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 上游密钥管理 | 列表（脱敏）/新增/删除上游密钥；查看最近错误码与连续失败次数 | S-01-01 | 完整值仅创建时返回一次 |

###### S-01-02 客户端密钥维护

**功能说明**：客户端密钥签发与撤销。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 客户端密钥管理 | 列表（脱敏）/签发（含名称备注）/撤销客户端密钥；查看最近使用时间 | S-01-02 | 撤销为软删除 |

###### S-01-03 密钥启停

**功能说明**：手动启停。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 密钥启停 | 在上游/客户端密钥列表内启用/停用密钥 | S-01-03 | 不自动停用 |

##### 2.1.1.2 S-02 用量观测

**功能说明**：状态与用量可视化。

###### S-02-01 运行状态看板

**功能说明**：运行概览。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 运行看板 | 服务状态/上游/密钥数/鉴权模式；今日请求/错误/429 计数卡片 | S-02-01 | 首页 |

###### S-02-02 用量统计

**功能说明**：维度统计。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 用量统计 | 按密钥/模型/状态维度的请求量与 token 图表；小时/天切换 | S-02-02 | token 尽力统计 |

###### S-02-03 请求日志查询

**功能说明**：明细查询。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 请求日志 | 最近请求明细列表；按密钥/模型/状态/时间筛选；分页 | S-02-03 | 保留 30 天 |

#### 2.1.2 基础数据域

**应用域概述**：只读运行配置。

##### 2.1.2.1 D-01 运行配置

**功能说明**：配置查看。

###### D-01-01 配置概览

**功能说明**：只读展示。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 运行配置 | 只读展示上游地址/超时/鉴权模式 | D-01-01 | env 来源，不可编辑 |

#### 2.1.3 平台支撑域

**应用域概述**：健康探针（管理员可见）。

##### 2.1.3.1 P-01 健康自检

**功能说明**：存活探针。

###### P-01-01 健康检查

**功能说明**：健康端点。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 健康检查 | 看板内展示 /health 结果 | P-01-01 | 公开端点 |

## 2.2 客户端调用方（ApiClient）

**用户类型概述**：持客户端密钥调用中转 API 的外部客户端（LobeChat/NextChat/SDK/脚本），无管理台 UI。

#### 2.2.1 核心业务域

**应用域概述**：中转 API 调用（非 UI 菜单，以功能点描述）。

##### 2.2.1.1 C-01 请求中转

**功能说明**：OpenAI 兼容 API 透传。

###### C-01-01 客户端鉴权 / C-01-03 请求透传 / C-01-04 回传

**功能说明**：API 调用功能点。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| （无 UI）对话补全 | POST /v1/chat/completions（流式/非流式），Bearer 客户端密钥 | C-01-01/03/04 | OpenAI 兼容 |
| （无 UI）模型列表 | GET /v1/models | C-01-03/04 | 透传 |
| （无 UI）其他 /v1/* | embeddings 等原样透传 | C-01-03/04 | 不解析 |
