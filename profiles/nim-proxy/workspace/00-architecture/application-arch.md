## 第一部分：文档概述

将业务架构映射为应用域/功能模块/功能子模块，标注用户类型与调用关系。系统为单体服务，双部署目标（服务器 / Workers），平台差异收敛在平台支撑域。

### 1.1 背景与目标

在保持中转透传本质的前提下，把密钥治理与用量观测组织为独立支撑能力，把双目标运行时差异隔离为平台适配。

### 1.2 文档定位

| 定位 | 说明 |
|------|------|
| 本文档做什么 | 业务→应用域/模块/子模块映射，标注用户类型、调用关系、DDD 分层 |
| 本文档不做什么 | 不涉及具体功能点描述、详细设计、技术实现与部署方案 |

### 1.3 范围

| 范围 | 说明 |
|------|------|
| 业务域 | NIM API 中转服务 |
| 应用域 | 核心业务域 / 支撑业务域 / 基础数据域 / 平台支撑域 |
| 用户类型 | 管理员（Owner）、客户端调用方（ApiClient） |

## 第二部分：应用架构

### 本架构概览

核心业务域承载请求中转主链；支撑业务域提供密钥治理与用量观测；基础数据域提供只读运行配置；平台支撑域提供健康自检、双目标运行时适配与遥测采集。支撑域被核心域调用（读密钥）并消费核心域产生的遥测。

### 应用域分层

| 分层 | 说明 | 包含功能模块 |
|------|------|-------------|
| 核心业务域 | 承载核心业务价值，中转主链 | C-01 请求中转 |
| 支撑业务域 | 为核心业务提供密钥治理与观测支撑，含业务规则 | S-01 密钥管理、S-02 用量观测 |
| 基础数据域 | 系统级只读引用数据 | D-01 运行配置 |
| 平台支撑域 | 纯技术能力，零业务语义 | P-01 健康自检、P-02 运行时适配、P-03 遥测采集 |

### 2.1 核心业务域

**应用域概述**：请求中转主链，服务客户端调用方；一次请求经鉴权→选钥→透传→回传完成，失败换钥重试。

#### 2.1.1 C-01 请求中转

**功能说明**：把客户端请求安全、原样地送达上游并回传结果，是系统的核心价值。

**涉及用户类型**：- [ ] 管理员（Owner） - [✓] 客户端调用方（ApiClient）

##### 2.1.1.1 C-01-01 客户端鉴权

**功能说明**：校验客户端密钥；未配置时纯透传。

**涉及用户类型**：- [ ] 管理员（Owner） - [✓] 客户端调用方（ApiClient）

**调用关系**：

| 调用模块/子模块 | 调用说明 |
|---------------|---------|
| S-01 密钥管理 | 读取启用的客户端密钥做校验 |

##### 2.1.1.2 C-01-02 上游密钥选择与轮询

**功能说明**：从启用的上游密钥池选取一把。

**涉及用户类型**：- [ ] 管理员（Owner） - [✓] 客户端调用方（ApiClient）

**调用关系**：

| 调用模块/子模块 | 调用说明 |
|---------------|---------|
| S-01 密钥管理 | 读取启用的上游密钥池 |

##### 2.1.1.3 C-01-03 请求透传

**功能说明**：原样转发请求，剔除逐跳头，替换上游 Authorization。

**涉及用户类型**：- [ ] 管理员（Owner） - [✓] 客户端调用方（ApiClient）

**调用关系**：

| 调用模块/子模块 | 调用说明 |
|---------------|---------|
| P-02-02 出站 HTTP 适配 | 经平台适配器发起上游请求 |

##### 2.1.1.4 C-01-04 流式与非流式回传

**功能说明**：SSE 逐块回传 / 非流式整体回传。

**涉及用户类型**：- [ ] 管理员（Owner） - [✓] 客户端调用方（ApiClient）

|---------------|---------|

**涉及用户类型**：- [ ] 管理员（Owner） - [✓] 客户端调用方（ApiClient）

**调用关系**：

| 调用模块/子模块 | 调用说明 |
|---------------|---------|
| C-01-02 上游密钥选择与轮询 | 取下一把密钥 |

## 第三部分：应用架构树

```
NIM Proxy
├── 核心业务域
│   └── C-01 请求中转
│       ├── C-01-01 客户端鉴权 — 校验客户端密钥/纯透传
│       ├── C-01-02 上游密钥选择与轮询 — 选启用上游密钥
│       ├── C-01-03 请求透传 — 原样转发
│       ├── C-01-04 流式与非流式回传 — SSE/整体回传
│       └── C-01-05 失败换密钥重试 — 401/403/429 换钥
├── 支撑业务域
│   ├── S-01 密钥管理
│   │   ├── S-01-01 上游密钥维护 — 增删查+健康
│   │   ├── S-01-02 客户端密钥维护 — 签发/撤销
│   │   └── S-01-03 密钥启停 — 手动启停
│   └── S-02 用量观测
│       ├── S-02-01 运行状态看板 — 状态/计数
│       ├── S-02-02 用量统计 — 维度统计
│       └── S-02-03 请求日志查询 — 明细查询
├── 基础数据域
│   └── D-01 运行配置
│       └── D-01-01 配置概览 — 只读 env 展示
└── 平台支撑域
    ├── P-01 健康自检
    │   └── P-01-01 健康检查 — 存活探针
    ├── P-02 运行时适配
    │   ├── P-02-01 组合根装配 — 双入口
    │   ├── P-02-02 出站 HTTP 适配 — httpx/workers.fetch
    │   └── P-02-03 仓储适配 — SQLite/D1
    └── P-03 遥测采集
        ├── P-03-01 请求日志写入 — 只读检视写日志
        └── P-03-02 用量聚合 — 小时/天聚合
```

## 附录

平台支撑域（P-02/P-03）为内部技术能力，不对应 BA 业务节点，按归类原则补充；其用户类型为空（系统内部）。
