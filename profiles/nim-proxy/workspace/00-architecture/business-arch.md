## 第一部分：文档概述

NVIDIA NIM 的 OpenAI 兼容 API 中转服务：客户端用自定义密钥访问，真实 NIM 密钥只存服务器；请求原样透传，配套管理台做密钥治理与用量观测。

### 1.1 背景与目标

把分散在环境变量里的密钥与配置变成可治理、可观测的对象，同时保持中转的透传本质与双部署目标（自建服务器 / Cloudflare Workers）。

### 1.2 文档定位

| 定位 | 说明 |
|------|------|
| 本文档做什么 | 描述业务域内 L2/L3/L4 层级结构与业务关系，不涉及系统实现 |
| 本文档不做什么 | 不划分应用模块、不标注用户类型、不涉及技术选型与系统架构 |

### 1.3 层级定义

| 层级 | 名称 | 说明 |
|------|------|------|
| L1 | 业务域 | 系统覆盖的业务范围 |
| L2 | 业务阶段 | 业务的时间阶段划分 |
| L3 | 关键业务 | 各阶段内的关键业务能力 |
| L4 | 业务活动 | 关键业务下的具体业务活动 |

### 1.4 范围

| 范围 | 说明 |
|------|------|
| 业务域 | NIM API 中转服务 |
| 业务阶段 | 接入与转发、运维与治理 |

## 第二部分：业务架构

### 本架构概览

两个业务阶段：「接入与转发」是运行时主链（客户端请求经鉴权、选钥、透传、回传完成一次中转）；「运维与治理」是管理面（密钥治理、用量观测、配置查看），为运行时提供可治理的密钥与可观测的遥测。两阶段通过「密钥」与「请求遥测」两类数据耦合。

### 2.1 接入与转发

**业务说明**：运行时主链，承载中转的核心价值——把客户端请求安全、原样地送达上游并回传结果。

##### 2.1.1 请求中转

**业务说明**：一次中转请求的完整处理。所属 L2：接入与转发。

###### 2.1.1.1 客户端鉴权

**业务说明**：校验客户端出示的客户端密钥；未配置密钥时为纯透传模式。所属 L3：请求中转。

###### 2.1.1.2 上游密钥选择与轮询

**业务说明**：从启用的上游密钥池中选取一把用于本次转发。所属 L3：请求中转。

###### 2.1.1.3 请求透传

**业务说明**：方法/路径/查询串/请求体原样转发，剔除逐跳头，替换上游 Authorization。所属 L3：请求中转。

###### 2.1.1.4 流式与非流式回传

**业务说明**：SSE 流式逐块回传并禁缓冲；非流式整体缓冲后按原状态码/头/体返回。所属 L3：请求中转。

###### 2.1.1.5 失败换密钥重试

**业务说明**：上游 401/403/429 且尚有未试密钥时换下一把重试（每把至多一次）。所属 L3：请求中转。

##### 2.1.2 健康自检

**业务说明**：对外暴露服务存活与基本配置概览。所属 L2：接入与转发。

###### 2.1.2.1 健康检查

**业务说明**：返回服务状态、上游地址、密钥数量、鉴权开关。所属 L3：健康自检。

### 2.2 运维与治理

**业务说明**：管理面，把密钥与配置变成可治理对象，把请求变成可观测遥测。

##### 2.2.1 密钥管理

**业务说明**：上游密钥与客户端密钥的全生命周期治理。所属 L2：运维与治理。

###### 2.2.1.1 上游密钥维护

**业务说明**：新增/查看（脱敏）/删除上游密钥，记录健康（最近错误码、连续失败次数）。所属 L3：密钥管理。

###### 2.2.1.2 客户端密钥维护

**业务说明**：签发/查看（脱敏）/撤销客户端密钥，含名称备注与最近使用时间。所属 L3：密钥管理。

###### 2.2.1.3 密钥启停

**业务说明**：手动启用/停用密钥（不自动停用），停用密钥不参与轮询/鉴权。所属 L3：密钥管理。

##### 2.2.2 用量观测

**业务说明**：运行状态与用量的可视化。所属 L2：运维与治理。

###### 2.2.2.1 运行状态看板

**业务说明**：服务状态、上游、密钥数量、鉴权模式、今日请求/错误/429 计数。所属 L3：用量观测。

###### 2.2.2.2 用量统计

**业务说明**：按密钥/模型/状态维度的请求量与 token（尽力）统计，小时/天聚合。所属 L3：用量观测。

###### 2.2.2.3 请求日志查询

**业务说明**：最近请求明细（时间/密钥/路径/模型/状态/延迟/token）查询与筛选。所属 L3：用量观测。

##### 2.2.3 运行配置查看

**业务说明**：只读展示运行参数（env 来源）。所属 L2：运维与治理。

###### 2.2.3.1 配置概览

**业务说明**：展示上游地址、超时、鉴权模式等只读配置。所属 L3：运行配置查看。

## 第三部分：业务架构树

```
NIM API 中转服务
├── 接入与转发
│   ├── 请求中转
│   │   ├── 客户端鉴权
│   │   ├── 上游密钥选择与轮询
│   │   ├── 请求透传
│   │   ├── 流式与非流式回传
│   │   └── 失败换密钥重试
│   └── 健康自检
│       └── 健康检查
└── 运维与治理
    ├── 密钥管理
    │   ├── 上游密钥维护
    │   ├── 客户端密钥维护
    │   └── 密钥启停
    ├── 用量观测
    │   ├── 运行状态看板
    │   ├── 用量统计
    │   └── 请求日志查询
    └── 运行配置查看
        └── 配置概览
```

## 附录

### 附录A：L3 业务依赖关系

| 上游 L3 | 依赖方向 | 下游 L3 | 依赖说明 |
|---------|---------|---------|---------|
| 密钥管理 | → | 请求中转 | 提供启用的上游/客户端密钥 |
| 请求中转 | → | 用量观测 | 产生请求遥测 |
| 运行配置查看 | → | 请求中转 | 展示其运行参数（只读） |

### 附录B：业务术语表

| 术语 | 定义 | 备注 |
|------|------|------|
| 上游密钥 | 调用 NIM 的真实密钥（nvapi-） | UpstreamKey |
| 客户端密钥 | 访问本代理的自定义密钥 | ProxyKey/ClientKey |
| 透传 | 请求/响应字节原样转发，不改写 | ADR-001/012 |
| 纯透传模式 | 未配置客户端密钥，客户端 Authorization 原样转发上游 | auth_mode=relay_only |
