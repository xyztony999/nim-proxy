# 公共枚举池

> 公共枚举（跨业务域通用）。格式：code + label。
> `status: draft` 是 `/profile kb` 生成的草稿候选，D1 / D3 定稿后去标；未定稿的条目不得被接口直接引用。

| 枚举标识 | code | label | status | 备注 |
|----------|------|-------|--------|------|
| enable_status | enabled | 启用 | draft | 候选：引入对象启停能力时启用 |
| enable_status | disabled | 停用 | draft | 候选 |
